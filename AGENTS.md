- The Between app lives in src/between (plain JSX, imported from the index route after hydration) because it reads browser-only state at render time.
- /sw.js is generated by scripts/build-sw.js after `vite build` and registered only via src/between/register-sw.js, so preview/dev never get a service worker.
- Between logic tests use node:test (`bun run test:between`) since they were authored for it.
